# Golf Cart Disaster! — V0.9 · 第一关试玩

**仅打磨 0–400 m。** 一辆车、一位富豪、一颗球、一座坡。目标是让乘客在惯性、接触和抓握之间摇摇欲坠，同时给驾驶者留下救回机会。

[直接试玩第一关](https://kimliumingyang.github.io/golf-cart-disaster/GolfCartDisaster.html?v=0.9) · [三段真实物理事故录像](https://kimliumingyang.github.io/golf-cart-disaster/public/walkthrough.html?v=0.9) · [22 次驾驶测试 / 参数 / 已知问题](QA_V0.9.md)

## 本轮范围

- 0–120 m：司机学习油门、刹车、滑行与小起伏。
- 120 m：停稳接富豪，人物自然坐好。
- 175–195 m：固定球击，可抢先通过、刹停躲避，也可能擦碰、挂住或翻倒。
- 235–325 m：主坡及坡顶，观察惯性、腾空、车身姿态和人员碰撞。
- 360 m：浅球洞，不需要跳跃。
- 400 m：在贵妇站点附近停稳，司机和富豪回到车内后显示 **STAGE 1 COMPLETE!**，不进入第二关。

原始 1500 m 地图、后续乘客、水管、超高坡和原鹅事件代码 / 数据保留；本轮运行时与验收均限定第一关。后续开发和优化暂停。

## 操作与救回

- **D / → / GAS**：油门。**A / ← / BRAKE**：先制动，低速后倒车；倒退时用油门抑制后退。
- **W / ↑ / NOSE UP**：抬车头。**S / ↓ / NOSE DOWN**：压车头。空中效果更明显，力矩有上限。
- **Space / HOP**：接地小跳，1.5 s 冷却；通常不需要跳。
- **P / Esc**：暂停；**R**：立即从 0 m、仅司机重开；**♪**：静音。
- **G / GOOSE**：鹅动画无害预览；正常路线约 334 m 也会展示一次。
- **ART**：保留 PNG / SVG 素材工作台，上传只影响视觉。

乘客短暂离座、飞高或侧挂都不会立即死亡。别在慌乱时持续踩油门把车从他身下开走：尝试减速、反向、修正车体，给他接触车身与落回的时间。手够得到扶手才会创建弱抓握，强冲击会使其断开；落稳后会放手。没有随机强制弹飞、骨盆牵引回座位或恢复动画。

120 m 和 400 m 站点范围为 ±3 m，车速低于 1 m/s 持续 0.6 s。最终还必须让两个人在车内、车体基本正立；如果有人仍挂在外面，会继续允许救回，不会自动归位或强制判死。

## 启动 / 构建

Node 20.19+ 或 Node 22.12+：

```sh
npm install
npm run dev
npm run package
npm run preview -- --port 4176
```

`dist/` 是静态网页构建。`npm run package` 另生成内嵌所有项目 PNG / 鹅图集的 `GolfCartDisaster.html`，可下载后打开，也写入 `work/package/index.html` 便于独立测试。托管浏览器若禁用 file://，请通过静态服务器打开。

GitHub main/root 的源模块不能直接执行时会转到此内嵌 HTML。`gh-pages` 分支也保留同版可玩文件。

## 测试与录像复现


浏览器测试默认 `/usr/bin/chromium`，可用 `CHROMIUM_PATH` 指向本机 Chrome/Chromium；也可指定 `GAME_URL`。

- 六项单测：阶段边界、保留后续数据、连续地形、32° 主坡、浅洞、两套鹅素材尺寸、单位换算。
- `test:e2e`：22 次第一关驾驶尝试，包含 21 条不同输入轨迹，记录成功、救回、抓握断开、失败与未完成；不测试后续关卡。
- `test:controls`：真实键盘事件、W/S、触控布局、暂停 / 失焦、素材工作台、重开、鹅预览不改变物理。

`?debug=1` 显示物理状态。H 碰撞轮廓、T 保守第一关测试驾驶、L 半速。正常试玩不显示自动驾驶。录像从 0 m 重算普通输入，在事故前才截取画面，每帧两步 60 Hz 求解、以 30 fps 输出，无音轨。片尾有约一秒冻结用于阅读，不是事故动画。

## 物理实现

Matter.js + Canvas，40 px/m，固定 60 Hz。角色仍为 11 个可碰撞刚体，包含头、躯干、骨盆、上下臂和大小腿。人-人、人-车、人-地形接触保留，自碰撞为关节稳定性关闭。

V0.9 将座位稳定约束改为仅上车 1 s；之后依靠物理座垫、摩擦、有限姿态力矩。离座时姿态支撑会变弱。手部与附近扶手形成独立、可断开的约束；掉人判定依据真正的地面 / 低位分离状态，保留 2.5 s 恢复时间，空中高处本身不算丢人。倒扣并不动 5 s 才判车辆无法恢复。

悬挂增加高位软导向，避免原两条对角约束的镜像解导致车轮反到车身上方。驱动、制动、倒车和姿态控制都通过力 / 力矩作用，没有逐帧钉住车速或坐姿。球只在首次真实碰撞求解后移除；第一关质量从旧 180 调为 90，速度仍 34 m/s，避免主要依赖猛烈必死迎击。

完整参数与测得的结果见 [QA_V0.9.md](QA_V0.9.md)。重点仍是实际手感，不把“有刚体”或“脚本可赢”当作趣味性证明。

## 美术与鹅

`public/assets/` 按 UI、角色、车辆、环境、特效分类；`originals/` 保留先前 PNG 原文件。ART 优先使用当前浏览器的 IndexedDB 上传，其次 manifest，缺失时继续代码绘制。上传不是服务器共享素材库；要全站生效，更新项目素材与 manifest 后构建发布。

两个鹅包都保留在 `public/assets/characters/goose/`，完整 12 帧包作为当前预览，按 110 ms 基础时序播放进场、叫声与离场。它不是 Spine 骨骼数据，也没有物理碰撞体。源包 README 中的后期触发位置属于原始素材说明；本轮按最新需求移至第一关方便走查。

## 仍需你确认

目前有稳定可学的通关路径，也有实测救回与失败样本。但尚未完成真实手机、Safari/iOS、实际音频听感或真人趣味性评审。一个全油门冲坡样本到站后仍有人侧挂，试验时限内未完成；没有用自动复位掩盖它。自动分片美术的关节处仍有接缝，高速下坡镜头仍有一定滞后。

先根据第一关的手感反馈继续调参；后续关卡保持冻结。
